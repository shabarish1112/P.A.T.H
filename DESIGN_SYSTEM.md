# P.A.T.H. Interface System

The interface is intentionally modeled after a compact, modern dark analytics product rather than a generic AI dashboard.

## Visual language
- Black application canvas (`#030404`–`#050505`)
- Charcoal data surfaces (`#121314`–`#171819`)
- Hairline white borders at 5–8% opacity
- Cyan used only as an interaction/status accent
- Compact 8–14px radius system
- Low-noise typography and restrained shadows
- Subtle glass/backdrop blur on navigation and structural surfaces

## Interaction model
- Collapsible persistent desktop navigation
- Mobile overlay navigation
- Persistent density preference
- Global transaction search from the top bar
- Sticky navigation/header and table headers
- Hover/focus/active states across controls and rows
- Responsive analytical grids
- Contextual investigation actions

## Production UI principles
1. Prioritize information density over decorative blocks.
2. Use color only when it carries state or interaction meaning.
3. Treat anomaly score as a screening signal, never as an accusation.
4. Preserve human-review actions as explicit user decisions.
5. Keep the system legible on 1366px laptops through large displays.
